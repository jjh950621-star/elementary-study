초등인강·학습지 추천 비교 사이트

1. GitHub에 elementary-study 저장소를 Public으로 만들고 README를 체크합니다.
2. 이 ZIP을 압축 해제하고, 안의 파일과 posts 폴더를 저장소 최상위에 업로드합니다.
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. 사이트 주소: https://jjh950621-star.github.io/elementary-study/

새 글 추가 방법
- posts 폴더에 글 HTML을 추가합니다.
- posts.json 배열에 다음 예시처럼 글을 추가합니다.
  {"title":"글 제목","category":"저학년","description":"글 소개","date":"2026-11-05","url":"posts/글파일.html"}
- category는 저학년, 고학년, 브랜드 비교, 선택 가이드 중 하나로 입력합니다.
- 새 글 주소를 sitemap.xml에도 추가합니다.
- 광고 원고에는 적절한 경제적 이해관계 표시를 포함합니다.

현재는 원고가 없어 빈 목록이 표시됩니다.
